# Chat App + Threat Map

Chat real-time dengan dashboard honeypot.

## Fitur

- Chat multi-room (public + private + room PIN)
- Upload gambar max 5 MB
- Honeypot Cowrie - tangkap serangan SSH
- Threat Map - peta dunia dengan marker
- GeoIP lookup - lokasi penyerang real-time
- Command status - suhu, CPU, RAM, load

## Teknologi

- Backend: Node.js, Express, Socket.IO
- Database: SQLite (sql.js)
- Honeypot: Cowrie SSH/Telnet
- Map: Leaflet.js + CartoDB
